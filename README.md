One fortune-cookie line for a crypto trader who has just been liquidated: a small, oracular promise whose punchline is the bill the trader already paid. A deterministic, standard-library-only Python program writes the line to `/output/entry.txt` for make.fun's "Fortune Cookie for the Liquidated Trader" bounty.

## Run it

```sh
python3 main.py
```

The program verifies the line against the competition gate (one line, at most 20 words, 1 to 160 characters) and against its pinned SHA-256 and byte count before writing it, so the file it produces is byte-identical on every run.
